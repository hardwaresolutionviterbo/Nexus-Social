# Fase 4 · Blocco 2 — Rispondi, inoltra, elimina, reazioni

Ramo: `fase4/blocco2`. Nessuna modifica al server: tutto viaggia cifrato dentro i messaggi.

## Cosa c'è
- **Tieni premuto un messaggio**: sei reazioni rapide (👍 ❤️ 😂 😮 😢 🙏), Rispondi, Copia, Inoltra, Elimina.
- **Rispondi**: barra «Rispondi a…» sopra il campo di testo; nel fumetto la citazione con il nome («Tu» o l'altra persona).
- **Inoltra**: fino a 5 chat per volta; il messaggio porta l'etichetta «Inoltrato».
- **Elimina per tutti**: solo i propri messaggi, entro 48 ore; resta «Hai eliminato questo messaggio» / «Questo messaggio è stato eliminato». **Elimina per me**: sparisce solo dal proprio telefono.
- **Reazioni**: una per persona per messaggio; toccare di nuovo la stessa la toglie. Non contano come messaggi non letti.
- Solo chi ha scritto un messaggio può eliminarlo per tutti (controllato sul telefono di chi riceve).

## Test
- Cifratura MLS vera: risposta, reazione (messa e tolta), elimina per tutti, divieto di eliminare i messaggi altrui, inoltro a una richiesta, elimina per me.
- File della chat sul telefono: messaggi, citazioni, reazioni ed eliminazioni restano dopo la riapertura.
- Schermate: tieni premuto → rispondi, reazione, elimina per tutti, inoltra.
- Esito: 275 test superati.
